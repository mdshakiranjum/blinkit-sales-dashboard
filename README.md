# Blinkit Sales & Business Performance Dashboard

## 📊 Project Overview

This project presents an interactive **Blinkit Sales & Business Performance Dashboard** created using **Microsoft Excel**.

The dashboard provides a visual analysis of sales performance across different outlet characteristics, item types, fat content, outlet locations, outlet sizes, and outlet types.

## 🖼️ Dashboard Preview

![Blinkit Sales Dashboard](Dashboard%20Screenshort.png)

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze overall sales performance
- Compare sales across different outlet locations
- Analyze sales by outlet size
- Analyze sales by outlet type
- Identify top-performing item categories
- Compare sales based on fat content
- Analyze outlet establishment trends
- Track important business KPIs

## 📌 Key Performance Indicators

The dashboard includes the following KPIs:

- **Total Sales:** $1.20M
- **Average Sales:** $141
- **Number of Items:** 8,523
- **Average Rating:** 4.0
